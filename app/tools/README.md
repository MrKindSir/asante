# Asante tools

Runtime AI workers and research collectors live in the Asante API package:

- `app/services/api/asante_api/ai/research.py` — web, news, and social/video evidence collectors
- `app/services/api/asante_api/ai/workers.py` — planner, researcher, and verifier workers
- `app/services/api/asante_api/workers_api.py` — portal worker endpoints

Use the Research room in the contributor portal (`Prepare a story plan` / `Find evidence sources`) against those API workers.
